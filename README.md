# Слово — платформа для авторов

Сайт о написании статей с личным кабинетом, статистикой просмотров, удобным редактором и полным SEO-слоем. Интерфейс сделан в духе dzen.ru: лента в три колонки, категории, крупные карточки, функции сохранения и понятная навигация.

## Запуск

```powershell
cd "C:\Работа с AI\article-platform"
python -m pip install -r requirements.txt
python app.py
```

Откройте http://127.0.0.1:5000

**Демо-доступ:** `demo@slovo.ru` / `demo123` (кнопка «Подставить данные» на странице входа).

## Что умеет

### Для читателя
- **Умная лента «Интересное»** по умолчанию: свежесть, вовлечённость (просмотры/лайки/комментарии), подписки, интересы по сохранённому и прочитанному, штраф за уже прочитанное, небольшое исследовательское смещение и ограничение однообразия (не больше двух статей одного автора в начале ленты). Лента стабильна для одного пользователя в течение дня.
- Фильтры по темам, поиск и сортировки: новые / популярные / по лайкам / по обсуждениям.
- Лента «Подписки» и подписки на авторов.
- Страница статьи с оглавлением, временем чтения, похожими статьями и комментариями.
- Лайки, сохранение в «Закладки» и копирование ссылки.
- Светлая и тёмная темы.

### Для автора
- Регистрация и вход, профиль с аватарой-эмодзи и биографией.
- Редактор с Markdown-разметкой, панелью форматирования и живым предпросмотром.
- Автосохранение: локально в браузере и на сервере каждые 20 секунд.
- Черновики и публикации, редактирование и удаление своих статей.
- Личный кабинет: обзор, список статей, фильтр по статусу, свежие комментарии.
- Статистика: уникальные просмотры по дням, график за 7/30/90 дней, источники трафика, топ статей.
- SEO-настройки каждой статьи: SEO-заголовок, описание, ключевой запрос и чеклист качества.

### Тестовая экономика (заработок автора)
- **Подписки** на авторов и отдельная лента «Подписки» на главной.
- **Поддержка статьи**: читатель отправляет автору 50/100/300 или любую сумму от 10 до 1000 тестовых кредитов.
- **Начисления за просмотры**: каждый день между авторами распределяется пул 100 кредитов пропорционально уникальным просмотрам (учёт по дням, без повторного начисления).
- **Бонус 50 кредитов** за первую публикацию статьи.
- **Кошелёк** в шапке и на странице «Монетизация»: баланс, заработанное, журнал операций, график доходов.
- **Заявки на выплату**: минимум 500 кредитов, один активный запрос одновременно, способ получения в тестовом режиме.
- **Админка выплат** (`/admin/payouts`) для демо-админа: выплатить или отклонить; при отклонении кредиты возвращаются автору.
- Всё помечено как **тестовый режим** — реальные деньги и платёжные системы не задействованы.
- Демо-админ: `demo@slovo.ru` / `demo123` (в кабинете есть пункт «Выплаты (админ)»).

### SEO и выдача
- ЧПУ-ссылки (slug) с транслитерацией.
- Уникальные `<title>` и `<meta description>` для каждой статьи.
- `canonical`, Open Graph, Twitter Card.
- JSON-LD разметка `BlogPosting` (автор, даты, просмотры, ключевые слова).
- `robots.txt`, `sitemap.xml`, RSS-лента (`/rss.xml`).
- Семантическая вёрстка: `article`, `header`, `main`, `nav`, заголовки H1–H3.

## Структура

```
article-platform/
├── app.py                 # Flask: маршруты, API, SEO, авторизация
├── db.py                  # SQLite: схема, миграции, демо-данные
├── requirements.txt
├── instance/site.db       # база создаётся при первом запуске
├── .secret_key            # ключ сессий создаётся автоматически
├── static/
│   ├── css/style.css      # дизайн-система и адаптив
│   ├── js/app.js          # интерактив, графики, редактор
│   └── img/og-default.svg
└── templates/
    ├── base.html, index.html, article.html, auth.html
    ├── dashboard_base.html, dashboard.html, my_articles.html
    ├── stats.html, saved.html, profile.html
    ├── monetization.html, admin_payouts.html
    ├── editor.html, error.html, _macros.html
```

## Технологии

Python 3.15 · Flask · SQLite · Vanilla HTML/CSS/JS · Chart SVG без внешних библиотек.

Никаких внешних CDN — сайт полностью работает офлайн.
